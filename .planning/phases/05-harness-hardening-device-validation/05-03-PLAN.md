## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route/context state → lever application | the context is the ONLY gate for degradation; a misread route applies levers on a social surface — the HARN-03 failure |
| detour → session state | entering/leaving a preserved route must be fully transparent (no state change) except the legitimate re-application on return |
| overlay → social surfaces | the counter must never be visible on preserved routes (its own predicate + the matrix) |
