## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Counter text | 13px | 500 (medium) | 1.4 |

**Contract:** ONE type token — the counter is the only text surface in the phase. `font-variant-numeric: tabular-nums` so digit changes don't shift the pill width (stable layout during the 1/s updates).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | **None — surface is strictly read-only** (`pointer-events: none`, OVER-01). No CTA, no interaction copy, no dismissal. |
| Counter readout | `{minutes} {unitLabel}` — e.g. "12 min". `{minutes}` = floored session minutes; `{unitLabel}` = `"min"` from the frozen `CONFIG.overlay` block (CORE-05). Single space separator. |
| Empty state | **Not applicable** — the counter renders only while visible (phase ≥ 1, REELS, visible, not fullscreen). There is no "no data" state by design (D-1). |
| Error state | **Not applicable** — the overlay is presentation-only; engine failures surface via the engine's console/event contract, never the overlay. No error copy. |
| Destructive confirmation | **None** — no destructive actions in this phase. |

**Tone contract (from discussion):** purely factual, zero judgement — no explanatory copy, no guilt-framing, no acknowledgment of degradation (D-7). The text is a number and a unit, nothing more.
